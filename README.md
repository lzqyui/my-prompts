# 现有一个大类的词库

# 词库1：学术研究与论文复现提示词库

整理和复用学术研究中的提示词、操作流程与记录模板，覆盖文献检索、论文筛选、精读翻译、论文写作、组会汇报和论文复现，并收录学习方法、上下文整理及工具速查资料。

使用时按当前任务选择对应文件，补充论文、研究主题、模型、数据集和运行环境等实际信息。文件中的专业、题目、模型链接和本地路径需要根据自己的任务调整。

## 快速开始

1. 在下方目录中找到当前任务对应的文件。
2. 打开文件，选择其中适合当前场景的一段提示词。`.txt` 和 `.md` 文件可以直接阅读；`.docx` 文件可下载后用 Word 或 WPS 打开。
3. 替换 `[研究问题]`、`[关键词1]`、`【粘贴论文】` 等占位内容，并补充实际输入材料。
4. 将提示词发送给所使用的 AI 助手，说明当前目标、已有信息、约束和期望输出。
5. 核对结果，记录需要继续补充或验证的内容，再进入下一步。

复现 SOP、检查清单和开发记录模板可以复制到具体项目中使用，随后按实际执行情况更新。

## 按任务选择文件

### 查找和读懂论文

先用「寻找论文文献提示词」设计检索策略，再用「论文筛选提示词」做快速筛选。需要深入理解时，选择「读论文提示词_页面大模型」中的单篇精读、方法解析或多篇对比；需要全文中文材料时使用「论文翻译」。

### 写作和组会汇报

用「论文编写提示词」梳理选题、大纲或具体章节，结合「写作时论文段落匹配参考文献」补充引用。准备组会时，使用「由论文内容生成ppt提示词」组织幻灯片内容与讲解稿。

### 复现论文和追踪问题

先阅读「论文复现标准SOP」，确定本次要完成推理验证、小规模训练闭环、训练流程复现还是完整基准复现。执行过程中用「repro_checklist」核对阶段结果，并持续填写「论文复现开发记录模板」，保留配置、命令、日志、结果和问题处理过程。

### 整理长任务和接续工作

使用「防溢出上下文提示词」整理目标、限制、真实进度、关键文件与下一步。接续前保存材料，在新对话中提供这些材料及所需文件，核对后继续。

## 使用说明

- **按实际场景替换示例。** 部分文件使用法学选题、脑 MRI 分割模型或特定本地路径作为例子，使用时需换成自己的研究内容与资源。
- **提供可核对的材料。** 论文原文、代码版本、数据说明和实验结果能帮助 AI 给出更具体的回答；信息缺失时应保留为待补充或待验证。
- **核实文献与研究结论。** 检查文献是否真实存在、DOI 是否对应所引用论文，以及论文内容是否支持当前论述。AI 生成的文字和建议需要人工审阅。
- **区分计划与执行结果。** SOP 和检查清单用于指导与记录工作，完成状态以实际日志、文件和验证结果为依据。
- **按当前环境调整命令。** Conda 命令和复现步骤需要结合操作系统、依赖版本、资源条件与工作目录使用。
- **确认所用工具的能力。** 文件中提到的 ECC、Skill 名称、联网检索、PPT 生成或历史记忆，需要相应工具与访问能力支持。复制提示词不会自动安装技能，也不会自动获得其他对话或项目的访问权限。
- **主动保存接续材料。** 上下文整理提示词可用于生成摘要和迁移材料；长期保存和新对话恢复需要实际保存并提供材料，具体记忆能力取决于所用工具。

## 后续维护

新增文件时同步更新目录中的链接和用途说明。修改提示词时，用提交说明记录调整的目标与原因，方便日后查找和对比版本。

新提示词建议包含：适用场景、需要提供的材料、提示词正文、期望输出和使用限制。已经试用过的条目可以另外记录所用模型、任务场景与效果，便于后续选择和改进。
